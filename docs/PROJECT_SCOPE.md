
# Project Scope

## Objective
Build a portfolio-grade Financial Crime Customer Risk and KYC/EDD analytics solution that simulates how a bank or fintech identifies high-risk customers, measures KYC completeness, prioritizes enhanced due diligence, manages remediation, and monitors review aging.

## Core workflow
Customer onboarding / periodic review → KYC completeness → customer risk score → risk tier → EDD trigger → case review → escalation / remediation / approval.

## Key risk factors
- PEP exposure
- Sanctions potential matches
- Adverse media
- High-risk geography
- Source-of-wealth verification
- Beneficial ownership completeness
- Identity / address / tax verification

## Disclaimer
All data is synthetic and created solely for portfolio demonstration.
